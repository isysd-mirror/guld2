# Spec 09 — P2P

**Status:** draft skeleton

## 1. Goals

- Discover peers  
- Gossip transactions  
- Propagate blocks / headers  
- Serve CAS objects on request  

## 2. Transport (**TBD**)

**Candidate:** libp2p (Noise + Yamux + identify). Alternative: custom TCP framing.

## 3. Message types (logical)

| Message | Payload |
|---------|---------|
| `Hello` | `chain_id`, `user_agent`, `best_height`, `guld_rules_hash` |
| `InvTx` / `GetTx` / `Tx` | tx ids / txs |
| `InvBlock` / `GetBlock` / `Block` | block hashes / blocks |
| `GetHeaders` / `Headers` | locator sync |
| `GetObjects` / `Objects` | `ObjectId[]` → bytes (size-limited) |

## 4. DoS limits

Peers MUST enforce:

- Max message size  
- Rate limits  
- Object request batch caps  
- Ban scoring for invalid blocks/txs  

## 5. Component API — `guld-p2p`

```text
trait Network {
  fn broadcast_tx(&self, tx: Tx);
  fn broadcast_block(&self, block: Block);
  fn request_objects(&self, ids: &[ObjectId]) -> impl Stream<Object>;
  fn peer_count(&self) -> usize;
}
```

## 6. Open parameters

- Concrete stack + ports  
- Sync algorithm (headers-first)  
- Whether light clients use the same protocol
